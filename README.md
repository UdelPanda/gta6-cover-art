Vice City Case Files — a web app that turns your photo into GTA 6-style cover art. Multi-panel photographic covers (hero + three acts), a WANTED case file with your name, alias and wanted stars, four story templates, a comic filter that redraws any photo as an illustrated panel, and PNG export in three post sizes (1080×1080, 1080×1350, 1920×1080). Everything runs locally in your browser; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
